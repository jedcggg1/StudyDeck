# StudyDeck

### การทบทวนบทเรียนที่ไม่เคยพลาด แม้เน็ตจะตาย

แอปการ์ด Spaced Repetition สำหรับวิชา STEM
**ใช้ได้ทันที ไม่ต้องสมัครสมาชิก ไม่ต้องต่อเน็ต**

🎁 ทดลองเลย: study-deck-opal.vercel.app
(กด "Continue in Offline Mode" — เริ่มได้ใน 5 วินาที ไม่ต้องมีบัญชี)

---

# เคยเจอปัญหาเหล่านี้ไหม?

- อ่านหนังสือรอบเดียว **ลืม 80%** ในหนึ่งสัปดาห์
- แอปการ์ดยี่ห้ออื่น **บังคับสมัครก่อนใช้** แล้วเตือนใจกลางห้องเรียน "เชื่อมต่ออินเทอร์เน็ตไม่ได้"
- สูตรแคลคูลัสในแอปทั่วไป **พิมพ์ยาก แสดงผลเละ**
- ข้อมูลการเรียน **หายเมื่อเปลี่ยนมือถือ** เพราะทุกอย่างอยู่บนเซิร์ฟเวอร์ของคนอื่น

> ปัญหาไม่ใช่คุณขี้ลืม — ปัญหาคือเครื่องมือทบทวนไม่ได้ถูกออกแบบมาให้ "จำ"

---

# StudyDeck แก้ให้ทุกข้อ

| ความเจ็บปวด | StudyDeck ให้อะไร |
|---|---|
| ลืมเร็ว | ระบบ **SM-2 spaced repetition** เลือกวันทบทวนให้สมอง ทบทวนน้อยลง จำได้นานขึ้น |
| ต้องสมัครสมาชิก | **เริ่มใช้ได้เลย** ไม่มีบัญชี ไม่มีค่าใช้จ่าย |
| เน็ตหลุด = ใช้ไม่ได้ | **Offline-first 100%** — เครื่องบิน ลิฟต์ ห้องเน็ตตาย เรียนต่อได้ |
| สูตรคณิตเละ | **KaTeX** แสดงทุกสมการสวยเป๊ะ ทั้ง integral และสมการฟิสิกส์ |
| ข้อมูลหาย/ผูกติดเซิร์ฟเวอร์ | ข้อมูลอยู่ **บนเครื่องคุณ** กด export เป็นไฟล์ได้ทุกเมื่อ |

---

# เหมือนมีติวเตอร์ส่วนตัว ที่รู้ว่าคุณลืมอะไรไปแล้ว

- StudyDeck **จำได้ทุกการ์ด** ที่คุณเคยเปิด — และรู้ว่าเมื่อไหร่สมองคุณกำลังจะลืม
- ระบบจะ **วนการ์ดที่ลืมใกล้จะลืมกลับมาทบทวนก่อน** ไม่เสียเวลาทวนสิ่งที่จำได้แล้ว
- คะแนนแต่ละครั้ง (ลืม / ยาก / ได้ / ง่าย) ปรับแผนให้ทันที — เรียน 15 นาทีต่อวันก็เห็นผล

> เรียนน้อยกว่าแต่จำได้มากกว่า — นี่คือหลักการเดียวกับที่แพทย์ นักภาษาศาสตร์ และนักเรียนสอบแข่งขันใช้กันมานาน

---

# พร้อมสำหรับวิชาจริง ไม่ใช่แค่คำศัพท์

- 📐 **Calculus** — integral, derivative, แสดงสูตรเต็มรูปแบบ
- 🧪 **Chemistry** — ตารางธาตุ สมดุลปฏิกิริยา สูตรก๊าซ
- ⚡ **Physics** — กฎของนิวตัน คลื่น ไดนามิกส์
- มาพร้อม **เด็คตัวอย่าง 3 วิชา** พร้อมคำอธิบายไทย-อังกฤษ ใช้ได้ตั้งแต่เปิดแอป
- จะสร้างเด็คของตัวเองก็แค่หยิบโจทย์เก่ามาเปลี่ยนเป็นการ์ด

---

# ติดตั้งเหมือนแอปจริง ใช้งานเหมือนแอปจริง

- กด "เพิ่มลงหน้าจอโฮม" — **StudyDeck กลายเป็นแอปที่เปิดแบบออฟไลน์ได้ทันที**
- ไม่มีไอคอนโหลดหมุนๆ รอเน็ต ไม่มี popup ขออัปเดต
- ข้อมูลอยู่ในเครื่อง = **เปิดแอปทันที ไม่ต้องรอโหลด**
- สถิติการเรียน การลบเด็ค แก้การ์ด — ทุกอย่างทำงาน **เรียลไทม์ ไม่มี spinner**

> เทคโนโลยีที่อยู่เบื้องหลัง (PWA + Service Worker + IndexedDB) ทำให้ของฟรีที่ติดตั้งผ่านเว็บ ให้ความรู้สึกไม่ต่างจากแอปบนสโตร์

---

# ความเป็นเจ้าของข้อมูลคือจุดขาย

- บัญชีเรียนของคุณ **ไม่ใช่สินค้าของเรา** — ไม่มี tracking ไม่มีโฆษณา ไม่มี server เก็บข้อมูลการเรียนของคุณ
- อยากสำรอง? กด **Export JSON** ได้ไฟล์เดียวจบ
- อยากย้ายเครื่อง? ส่งไฟล์นั้นไปเครื่องใหม่ กด Import — **เสร็จใน 10 วินาที**
- อยากลองโดยไม่เปิดเผยตัวตน? โหมดออฟไลน์ **ไม่ต้องกรอกแม้แต่อีเมล**

---

# ทำไมถึงวางใจได้ (สำหรับสายเทค)

- **Open source ทั้งหมด** — github.com/jedcggg1/StudyDeck อ่านโค้ดได้ทุกบรรทัด
- โค้ดผ่านการรัน **ชุดทดสอบ SM-2 และ Import/Export 16 รายการ** ทุกครั้งก่อน deploy
- **DOMPurify** sanitize ทุกเนื้อหาก่อนแสดงผล — วางการ์ดจากคนอื่นได้อย่างปลอดภัย
- สถาปัตยกรรม **ไม่มี backend ของตัวเอง** = ไม่มีช่องโหว่ฐานข้อมูลให้รั่ว ไม่มีค่าเซิร์ฟเวอร์ให้จ่าย

> ฟรี ตลอดไป เพราะโครงสร้างมันถูกออกแบบมาให้ไม่ต้องพึ่งใคร

# เทียบให้เห็นชัด ๆ

| | แอปการ์ดทั่วไป | StudyDeck |

| เริ่มใช้ | สมัคร ยืนยันอีเมล รอโหลด | **5 วินาที ไม่ต้องสมัคร** |

| ข้อมูล | อยู่บนเซิร์ฟเวอร์เขา | ✅ อยู่บนเครื่องคุณ + export ได้ |
| ราคา | รายเดือน / มีโฆษณา | ✅ **ฟรี ไม่มีโฆษณา** |

# เห็นไหมว่าง่ายแค่ไหน

1. เปิดลิงก์ → กด **Continue in Offline Mode**
2. เลือกเด็ค Calculus / Chemistry / Physics ที่เตรียมไว้ให้
3. กดเรียน — ระบบจะเลือกการ์ดให้เองว่าวันนี้ควรทบทวนอะไร
4. ให้คะแนนแต่ละการ์ด — **แผนการทบทวนปรับให้ทันที**

> ถ้าคุณมีวิชาสอบใน 3 สัปดาห์ — นี่คือแอปที่ทำให้ 3 สัปดาห์นั้นเพียงพอ
